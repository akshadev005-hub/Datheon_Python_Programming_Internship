# Task 1 - Hangman Word Guessing Game

## Description
A terminal-based Hangman game developed using Python.
The player guesses a randomly selected English word
within six incorrect attempts.

## Features
- Random word selection
- External English word list
- Six incorrect attempts
- Seven ASCII Hangman stages
- Letter tracking
- Duplicate guess prevention
- Input validation
- Victory and defeat screens

## Technologies Used
- Python 3
- VS Code
- Random module

## How to Run
python hangman.py
