# Rule-Based Chatbot

## Description

A simple rule-based chatbot developed using Python. It interacts with users through text-based conversations by identifying predefined keywords and providing appropriate responses based on programmed rules.

## Features

- Interactive text-based conversation
- Predefined questions and responses
- Keyword-based input recognition
- Responds to greetings and common queries
- Handles unknown inputs with default responses
- Simple and beginner-friendly implementation

## Technologies Used

- Python 3
- VS Code

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

   `python chatbot.py`

## How It Works

1. The user enters a message.
2. The chatbot checks the input against predefined keywords or rules.
3. It displays the corresponding response.
4. If no matching rule is found, it provides a default response.
